# Production and CAPEX Scenario

## Base orientation case from A.I.P.S

| Item | Figure |
|---|---:|
| Proposed open pits | 4 |
| Average production per pit | 200 t/day |
| Proposed sulfide plant capacity | 800 t/day |
| Preliminary estimated resource | 2.3 Mt |
| Preliminary average grade | 1.8% Cu |
| Preliminary CAPEX | 124.4M MAD HT |
| Mine CAPEX | 3.41M MAD |
| Plant CAPEX | 96.06M MAD |
| Infrastructure CAPEX | 24.93M MAD |

---

## Interpretation

These figures should be treated as a **base orientation case**, not as a final project ceiling.

The project should also support:

- an upside case beyond the initial 2.3Mt hypothesis;
- staged plant development;
- modular pilot;
- future industrial scale-up after validation.

---

## Strategic language

Use:

**The A.I.P.S study provides a preliminary industrial reference case of 800 t/day and 124.4M MAD HT CAPEX. This case forms the initial engineering anchor, while the broader license potential should be tested through the 180-day feasibility upgrade.**
