# 30–90 Day Smart Exploration Phase

## Objective

Upgrade the exploration evidence and define priority copper targets.

## Tasks

- GIS mapping of license;
- trench and sample mapping;
- channel sampling plan;
- multi-element geochemistry;
- IP / Resistivity survey plan;
- blind-zone mapping;
- ore-type classification;
- short drilling target list.

## Outputs

- Copper Target Priority Map
- Blind-Zone Map
- Sampling Upgrade Plan
- Geochemistry Interpretation Memo
- IP / Resistivity Plan
- Short Drilling Target List
