# 90–120 Day Pilot Feed Definition

## Objective

Define what material can be used for pilot testing.

## Tasks

- targeted short drilling if approved;
- integrate geophysics and assays;
- classify ore by type and grade;
- exclude low-confidence material;
- select bulk sample locations;
- design metallurgical sample plan;
- prepare pilot decision gate.

## Outputs

- Pilot Feed Definition Memo
- Selective Extraction Plan
- Ore-Type Decision Matrix
- Metallurgical Sample Plan
- Pilot Decision Gate Memo
