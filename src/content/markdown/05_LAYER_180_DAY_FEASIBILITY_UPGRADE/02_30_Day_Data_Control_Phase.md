# 0–30 Day Data Control Phase

## Objective

Convert all existing documents into a structured digital evidence base.

## Tasks

- digitize A.I.P.S study;
- build license register;
- build evidence register;
- build sample/assay register;
- extract assumptions;
- detect contradictions;
- classify claims;
- build data room base;
- define investor disclosure levels.

## Outputs

- License Register
- Assumption Register
- Evidence Matrix
- Claims Control Matrix
- Data Gap Register
- 30-Day Validation Work Plan
