# AI Targeting and Decision Room

## Purpose

Design the digital decision room for Atlas Mining and qualified operators/investors.

---

## Dashboard modules

| Module | Purpose |
|---|---|
| License Dashboard | Shows license position and review status |
| Evidence Dashboard | Shows field/lab evidence maturity |
| Target Priority Map | Ranks zones by copper potential |
| Assay Matrix | Displays sample results and confidence |
| AIPS Assumption Tracker | Tracks study assumptions and validation status |
| CAPEX Scenario Tracker | Compares base/upside/expansion cases |
| 180-Day Roadmap | Shows progress through validation |
| Risk Register | Tracks technical/legal/commercial risks |
| Investor Access Log | Controls data-room access |

---

## Decision states

- Go
- Hold
- Redesign
- More data required
- Internal only
- Ready for operator review
