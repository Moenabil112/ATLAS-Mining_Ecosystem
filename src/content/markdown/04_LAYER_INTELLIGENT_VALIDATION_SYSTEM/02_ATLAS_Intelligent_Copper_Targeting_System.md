# ATLAS Intelligent Copper Targeting System

## Business explanation

The system helps answer one commercial question:

**Where should we spend money first, and where should we avoid wasting it?**

It organizes:

- license data;
- trench data;
- sample data;
- assay results;
- geological observations;
- photos;
- geophysics;
- drilling targets;
- processing results;
- risk notes.

Then it supports:

- target ranking;
- blind-zone detection;
- pilot feed selection;
- waste reduction;
- extraction selectivity;
- evidence-based negotiation.

---

## Core modules

1. License map
2. Sample and assay map
3. Target priority map
4. Blind-zone map
5. Ore-type classifier
6. Pilot feed selector
7. A.I.P.S assumption tracker
8. Investor decision dashboard

---

## Commercial value

The system helps prevent:

- blind drilling;
- overbuilding;
- processing weak material;
- premature CAPEX commitment;
- investor confusion;
- unsupported claims.
